# Scripting

个人使用的 [Scripting](https://scripting.fun/) 脚本合集。

## 脚本

- `Codex Usage`：查看 Codex 用量。
- `灵动岛时间`：在灵动岛显示时间。
- `IslandSeconds`：在灵动岛以 15 号字最小显示当前秒数，支持原地重新对时。[下载安装包](https://github.com/llle0x/scripting/raw/refs/heads/main/IslandSeconds.scripting)。
- `局域网互传`：通过局域网在浏览器与 Scripting 设备之间互传文字和文件，支持 6 位配对码和受信任浏览器自动连接。

每个目录都是可独立导入的 Scripting 项目，项目入口与权限配置见各目录下的 `script.json`。

[下载局域网互传（含灵动岛秒数）](https://github.com/llle0x/scripting/raw/refs/heads/main/局域网互传-灵动岛秒数.scripting)。在 iPhone 下载后使用 Scripting 打开并导入。
